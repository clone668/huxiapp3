## 自己也是作品

这个站本身就是一件作品：Astro 静态生成，没有后端，没有数据库，内容全是 Markdown。刊头 HUXI 是单线空心 SVG，入场时描边画一次；格言那行有水平扫光，14 秒一轮，播完停 9 秒。

版式按报纸做：刊头、日期行、双线、栏目标记。明暗双主题，跟随系统，手动选择存 localStorage。部署在 Vercel，源码在 GitHub 开源——仓库里的 README 有完整的开发文档（怎么加作品、改样式、本地跑起来）。
